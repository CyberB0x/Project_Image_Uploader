# О проекте "Image Uploader"

## **Главная страница**
- На главном странице есть мини галерея.
- При каждом обновлении страницы мини галерея меняет картинок
- Что бы загружать свою картинку нажмите на Take me to Showcase

# **Страница загрузки картинок**
- В этом странице тоже есть мини галерея
- Нужно загружать картинку не больше чем 5 МБ
- После загрузки вы получите ссылку на вашу картинку

# **Страница загруженных картинок**
- На этом странице вы увидите свою картинку
- Вы можете удалить их нажав на крестик
- Добавлен защита от вредоносных файлов Pillow 

# **Требования к окружению**
Перед развертыванием убедитесь, что у вас установлены:
- Python 3.8+
- pip (менеджер пакетов Python)
- Docker
- Nginx
- Pillow
- Виртуальное окружение (рекомендуется)
- ОС: Windows / Linux / macOS

# **Команды для запуска и остановки**
- Запуск docker compose up --build
- Остановка docker compose down

# **Описание маршрутов**
- GET /api/images/ Возвращает список загруженных изображений
- POST /upload/ Загружает изображение на сервер.
Тело запроса: Файл в бинарном формате
- DELETE /api/delete/ Удаляет изображение по его названию.
Заголовок запроса: Filename: 12345.png
